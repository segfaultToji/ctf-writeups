# CTF Writeups
My cybersecurity CTF learning repository documenting challenges, methodology, mistakes, solutions, and lessons learned.

## Platforms
- PicoCTF
- OverTheWire
- Root-Me

## Structure
```text
picoctf/
├── crypto/
├── forensics/
├── web/
├── reverse-engineering/
├── binary-exploitation/
└── general-skills/

overthewire/
└── bandit/

rootme/

notes/
```

## Writeup Format
Each writeup aims to document:
1. Challenge objective
2. Initial enumeration
3. Observations
4. Analysis
5. Exploitation or solution technique
6. Commands and tools used
7. Result
8. What I learned
9. Mistakes and better approaches

## Focus
The goal is not just collecting flags. The goal is understanding the underlying technique and being able to reproduce it independently.

## Ethics

Only authorized CTF environments and challenge targets are tested. Active competitions and platform rules are respected.
